# CLAUDE.md

Este proyecto es una app hecha en **Flutter**.

## Commits

Cada tarea terminada debe ir acompañada del commit correspondiente. No se considera una tarea completada hasta que su cambio esté commiteado.

## Versionado

La app tiene su propia versión (ver `pubspec.yaml`), empezando en `0.0.1` y siguiendo semver (`MAJOR.MINOR.PATCH`):

- **MAJOR**: cambios grandes / incompatibles.
- **MINOR**: tareas grandes o nuevas funcionalidades.
- **PATCH**: tareas menores o fixes.

Cada commit de una tarea que implique subir de versión debe actualizar el número de versión en `pubspec.yaml` acorde a lo anterior.

## Skills instaladas

Cuando sea necesario, usar las skills instaladas en este proyecto (`.agents/skills/`):

- **dart-best-practices** — buenas prácticas generales de Dart (estilo de código, Effective Dart, idioms del lenguaje).
- **dart-expert** — desarrollo experto en Dart, Flutter y apps multiplataforma/móvil.
- **flutter-apply-architecture-best-practices** — arquitectura en capas (UI, Lógica, Datos) para estructurar o refactorizar el proyecto.
